# byway-lists

Курируемый список доменов для [byway](https://github.com/Tomonj1/byway) —
раздельного туннелирования на роутере с OpenWrt.

Это тот самый список, который в панели byway называется
**«byway — основной список разработчика»**. Он же подключается командой:

```sh
byway presets
```

Отдельным репозиторием, а не внутри byway, по одной причине: список меняется
чаще программы. Сервис переехал на другой домен, у него появился новый CDN,
что-то разблокировали — это правка одной строки, и ради неё незачем выпускать
новую версию программы.

## Что внутри

`domains.lst` — по одной записи на строку. Строки с `//` — пояснения, они
разбиты на разделы по сервисам. Запись покрывает и поддомены: `example.com`
ловит и `mail.example.com`, поэтому короткие имена вроде `scdn.co` здесь
нормальны, даже если сам сайт по такому адресу не открывается.

`subnets.lst` — диапазоны адресов, 234 записи. Нужны сервисам, которые
работают не по именам: Telegram, Meta, Blizzard. **byway не забирает этот
файл сам** — пресет по устройству только доменный. Берите руками:

```sh
wget -O /etc/byway/subnets.lst \
  https://raw.githubusercontent.com/Tomonj1/byway-lists/main/subnets.lst
byway gen && /etc/init.d/byway restart
```

Свой список подсетей он при этом ЗАМЕНИТ — если там есть своё, сперва
сохраните или дописывайте в конец, а не поверх.

## Чего внутри нет, и это намеренно

- **Российских сервисов.** Банки, госуслуги, маркетплейсы и местные CDN
  нередко закрываются от зарубежных адресов и через VPN просто перестают
  работать. Им место мимо туннеля.
- **Целых доменных зон и чужих облаков.** Запись вида `.ua` или домен
  Cloudflare целиком уводит в туннель чужой трафик и режет скорость. По той
  же причине из `subnets.lst` вырезан блок Microsoft: у автора он есть, но
  это `20.64.0.0/10`, `40.64.0.0/10` и подобное — 33.6 миллиона адресов,
  практически весь Azure, и в чужом туннеле ему делать нечего. Здесь
  осталось 633 тысячи адресов, крупнейший блок — `/14`, и он принадлежит
  одной компании, а не облаку напрокат.
- **Того, что и так лечится другим способом.** Часть сервисов открывается
  обходом DPI (zapret и подобные), и домен должен жить РОВНО В ОДНОМ месте:
  разъехавшись на два выхода, одна сессия ломается не отказом, а сбоями при
  входе в аккаунт. byway говорит о таких пересечениях вслух при загрузке
  списка.

## Честно о пределах

Список собран руками для одного дома в России и проверяется тем, что этот дом
им пользуется каждый день. Ничего кроме этого за ним не стоит: ни автоматики,
ни массовых проверок, ни гарантий, что запись всё ещё нужна. Нашли лишнее или
недостающее — [заведите issue](https://github.com/Tomonj1/byway-lists/issues)
или пришлите pull request, это самое полезное, что можно сделать.

Список свободен: берите, копируйте, правьте под себя.
